# ELYSIA NO DENSETSU – Items & Inventory Asset Standards

## 1. Directory Structure
```
items/
├── consumables/ (HP potions, MP potions, stat food, town return scrolls)
├── materials/ (Herbs, ores, wood, monster hides, elemental fragments)
├── quest/ (Letters, ancient keys, ceremonial emblems, quest tokens)
└── special/ (Awakening certificates, treasure chests, lottery vouchers)
```

## 2. Icon Specifications
- **Dimensions:** 48×48 or 64×64 pixels square.
- **Format:** Transparent PNG or scalable vector SVG.
- **Rarity Visual Borders:**
  - Common: Slate Grey `#94a3b8`
  - Uncommon: Forest Green `#22c55e`
  - Rare: Azure Blue `#3b82f6`
  - Epic: Royal Purple `#a855f7`
  - Legendary: Sun Gold `#f59e0b`
  - Mythic / Unique: Crimson Flame `#ef4444` to `#dc2626`
