# ELYSIA NO DENSETSU – UI & HUD Asset Standards

## 1. Directory Structure
```
ui/
├── frames/ (Ornate gold filigree borders, parchment modal window frames)
├── panels/ (Vitals display, minimap radar bracket, chat dock backing)
├── buttons/ (Action wheel, utility circular buttons, tab pills)
├── icons/ (Class crests, status badges, compass directions)
└── inventory/ (Slot cells, paper doll silhouettes, drag feedback overlays)
```

## 2. Color Palette & Aesthetics
- **Theme:** Premium Anime Fantasy MMORPG.
- **Backgrounds:** Deep midnight blue (`#0a1128`), navy slate (`#0f172a`), translucent smoky obsidian (`rgba(11, 19, 41, 0.94)`).
- **Accents:** Antique royal gold (`#d4af37`), warm amber (`#f59e0b`), metallic brass (`#b45309`).
- **Parchment / Text:** Warm ivory (`#fffbeb`), platinum light (`#f8fafc`).
