# ELYSIA NO DENSETSU – Audio & Music Asset Standards

## 1. Directory Structure
```
audio/
├── music/ (Village peaceful theme, battle tension, boss encounter, dungeon ambience)
└── sfx/ (Sword slash, magic cast, level up chime, quest complete fanfare, coin jingle)
```

## 2. Audio Specifications
- **Format:** High-efficiency `.mp3` or `.ogg` for web streaming.
- **Normalization:** -14 LUFS for background music; -6 dB peak for combat sound effects.
